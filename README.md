# খবরের খাতা — বাংলাদেশ নিউজপেপার কীওয়ার্ড মনিটর

প্রতিদিন নির্বাচিত বাংলা পত্রিকার RSS ফিড থেকে প্রযুক্তি-সংক্রান্ত হেডলাইন (বিভাগ + কীওয়ার্ড হাইব্রিড পদ্ধতিতে)
বাছাই করে একটি ওয়েবপেজে (Cloudflare Pages) সাজিয়ে দেখায়, যাতে ফ্রি টাইমে একসাথে পড়া যায়।

## কীভাবে কাজ করে

```
GitHub Actions (প্রতিদিন cron)
   └─ fetch_news.py চালায়
        ├─ config.json থেকে পত্রিকা ও কীওয়ার্ড পড়ে
        ├─ প্রতিটি RSS ফিড টেনে কীওয়ার্ড মেলে এমন খবর বাছাই করে
        └─ public/news.json আপডেট করে ও রিপোতে কমিট করে
Cloudflare Pages
   └─ public/ ফোল্ডার থেকে অটো-ডিপ্লয় হয় (প্রতি push-এ)
        └─ index.html news.json পড়ে সুন্দরভাবে দেখায়
```

## PWA (মোবাইলে হোম-স্ক্রিনে ইনস্টল)

সাইটটি একটি Progressive Web App (PWA)। মোবাইল ব্রাউজারে খুলে "Add to Home Screen" /
"Install app" অপশন দিয়ে হোম স্ক্রিনে যোগ করা যায়, তখন এটি প্রায় নেটিভ অ্যাপের মতো
(নিজস্ব আইকন, ঠিকানা-বার ছাড়া পূর্ণ স্ক্রিন) খোলে।

- `public/manifest.json` — অ্যাপের নাম, থিম কালার ও আইকন তালিকা
- `public/sw.js` — service worker; শুধু অ্যাপ শেল (HTML, আইকন) অফলাইনে ক্যাশ করে
- `public/icons/` — বিভিন্ন সাইজের আইকন (ব্যবহারকারীর দেওয়া লোগো থেকে তৈরি)

**নোট:** অফলাইনে শুধু অ্যাপ শেল খোলে — খবরের ডেটা (`news.json`) ইচ্ছাকৃতভাবে কখনো
ক্যাশ থেকে দেখানো হয় না, প্রতিবার নেটওয়ার্ক থেকেই আনা হয়, যাতে খবর সবসময় টাটকা থাকে।
নতুন আইকন বা থিম কালার বদলাতে চাইলে `public/manifest.json` ও `public/icons/`
ফোল্ডার আপডেট করলেই হবে।

## ধাপ ১: GitHub রিপো তৈরি

1. GitHub-এ নতুন একটি **private বা public repo** বানান (যেমন `bd-news-monitor`)।
2. এই ফোল্ডারের সব ফাইল সেই রিপোতে push করুন:
   ```bash
   git init
   git add .
   git commit -m "initial setup"
   git branch -M main
   git remote add origin https://github.com/<আপনার-ইউজারনেম>/bd-news-monitor.git
   git push -u origin main
   ```

## ধাপ ২: কনফিগারেশন কাস্টমাইজ করুন

`config.json` ফাইলে চারটা অংশ:
- `feeds`: কোন কোন পত্রিকার RSS ফিড দেখা হবে
- `tech_path_hints`: খবরের লিংকে এই অংশগুলোর কোনোটা থাকলে সেটা সরাসরি "প্রযুক্তি বিভাগ"
  হিসেবে ধরে নেওয়া হয় (কীওয়ার্ড লাগে না)
- `keywords`: উপরেরটা না মিললে, টাইটেল/বিবরণে এই শব্দগুলোর যেকোনোটা থাকলে সেটাও যোগ হবে
- `retain_days`: কতদিনের পুরনো খবর পেজে রাখা হবে (ডিফল্ট ১৪ দিন)

কীওয়ার্ড যোগ/বাদ দেওয়া সবচেয়ে সহজ কাজ — শুধু `keywords` লিস্টে লিখুন বা মুছুন, বাকি
সিস্টেম নিজে থেকেই পরের রানে সেটা ব্যবহার করবে।

## ধাপ ৩: GitHub Actions চালু করুন

`.github/workflows/daily-news.yml` ফাইলটি এমনিতেই কাজ করবে — কোনো সিক্রেট/টোকেন সেটআপ
লাগবে না, কারণ এটি GitHub-এর নিজস্ব `GITHUB_TOKEN` ব্যবহার করে (repo push permission
আগে থেকেই থাকে)। শুধু নিশ্চিত করুন:

- রিপোর **Settings → Actions → General → Workflow permissions**-এ
  "Read and write permissions" সিলেক্ট করা আছে।

প্রথমবার টেস্ট করতে **Actions ট্যাব → Daily News Fetch → Run workflow** চেপে ম্যানুয়ালি
একবার চালিয়ে দেখুন। এটি সফল হলে `public/news.json`-এ নতুন কমিট পড়বে।

এখন দিনে দুইবার চলে (বাংলাদেশ সময় দুপুর ১২টা ও রাত ৮টা) — RSS ফিডে সাধারণত শুধু
সাম্প্রতিক কিছু আইটেম থাকে বলে দিনে একবার চেক করলে ব্যস্ত দিনে কিছু খবর ফিড থেকে
হারিয়ে যেতে পারত। সময়সূচি বদলাতে চাইলে workflow ফাইলের `cron:` লাইনগুলো বদলান
(এগুলো UTC সময়ে — বাংলাদেশ সময় থেকে ৬ ঘণ্টা বিয়োগ করে বসান)।

## ধাপ ৪: Cloudflare Pages-এ ডিপ্লয়

1. [Cloudflare Dashboard](https://dash.cloudflare.com/) → **Workers & Pages → Create → Pages
   → Connect to Git**
2. আপনার `bd-news-monitor` রিপো সিলেক্ট করুন
3. বিল্ড সেটিংস:
   - **Framework preset:** None
   - **Build command:** (খালি রাখুন)
   - **Build output directory:** `public`
4. **Save and Deploy** চাপুন

এরপর থেকে GitHub-এ যতবার পরিবর্তন commit হবে (GitHub Actions যখন news.json আপডেট করে
push করবে), Cloudflare Pages স্বয়ংক্রিয়ভাবে নতুন ভার্সন ডিপ্লয় করবে — কোনো ম্যানুয়াল কাজ
লাগবে না।

## লোকালি টেস্ট করা

```bash
pip install -r requirements.txt
python fetch_news.py
```

এটি `public/news.json` আপডেট করবে; `public/index.html` ব্রাউজারে খুললে ফলাফল দেখা যাবে
(লোকাল ফাইল থেকে fetch() ব্লক হতে পারে ব্রাউজার সিকিউরিটির কারণে — সেক্ষেত্রে
`python -m http.server` দিয়ে `public/` ফোল্ডার সার্ভ করে দেখুন)।

## কোনো সমস্যা হলে জানতে পারবেন কীভাবে

GitHub স্বয়ংক্রিয়ভাবে রিপোর মালিকের ইমেইলে সতর্কবার্তা পাঠায় যদি কোনো scheduled
workflow ব্যর্থ হয় (এটা GitHub-এর নিজস্ব ডিফল্ট ব্যবস্থা, আলাদা কিছু সেটআপ করা লাগে না)।
তাই কোনো ফিড ভেঙে গেলে বা config.json-এ ভুল হলে আপনি ইমেইলে জানতে পারবেন।

মাঝে মাঝে **Actions ট্যাব**-এ গিয়ে সাম্প্রতিক রানগুলো ✅ না ❌ দেখানো হচ্ছে সেটা চোখ
বুলিয়ে নেওয়াও ভালো অভ্যাস — বিশেষ করে কোনো পত্রিকা তাদের ওয়েবসাইট বদলালে ফিড URL
বদলে/বন্ধ হয়ে যেতে পারে।

## নতুন পত্রিকা RSS ফিড খুঁজে পাওয়া

বেশিরভাগ পত্রিকার সাইটে `/feed/` বা `/rss.xml` যোগ করলেই ফিড পাওয়া যায়, অথবা পেজের
সোর্স কোডে `type="application/rss+xml"` খুঁজুন।

## সীমাবদ্ধতা

- যেসব পত্রিকার RSS ফিড নেই, সেগুলো এই পদ্ধতিতে যোগ করা যাবে না (সরাসরি স্ক্র্যাপিং লাগবে,
  যা বেশি ভঙ্গুর ও রক্ষণাবেক্ষণ-সাপেক্ষ)।
- কীওয়ার্ড মিলটি সরল টেক্সট-ম্যাচিং (substring)। প্রসঙ্গভিত্তিক/স্মার্ট ফিল্টারিং দরকার হলে
  `fetch_news.py`-তে Claude API কল যোগ করে প্রতিটি হেডলাইন ক্লাসিফাই করানো যায়।
